Publish

Everything you edit in the tabs above saves instantly, but only in THIS browser — that's why it doesn't show up for guests or on other devices. Publish commits the current content straight into the site's files on GitHub, which makes it live for everyone within about a minute. This needs a GitHub Personal Access Token you generate yourself below — it's stored only in this browser and is never sent anywhere except directly to GitHub's own API.
